# Skalakart

A simple public repository starter for the `skalakart` project.

## Overview

This repository contains a minimal static landing page and a basic project setup.

## Files

- `index.html` – landing page
- `style.css` – page styling
- `.gitignore` – common ignores for local development

## Local preview

Open `index.html` in a browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
